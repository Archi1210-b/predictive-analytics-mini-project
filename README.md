# Predictive Analytics Mini Project: Customer Churn Prediction

## Overview
This project builds a predictive binary classification model using **Logistic Regression** to predict customer churn based on account attributes, demographics, and transaction history.

## Steps Implemented:
1. **Data Preprocessing & Cleaning**: Handled missing values and treated numerical outliers using the Interquartile Range (IQR) box plot method.
2. **Exploratory Data Analysis (EDA)**: Analyzed feature distributions and generated a correlation heatmap.
3. **Feature Engineering**: Applied One-Hot Encoding and standard scaling (`StandardScaler`).
4. **Model Training**: Trained a Logistic Regression classifier.
5. **Validation & Optimization**: Evaluated model performance using Confusion Matrix, F1-Score, and AUC-ROC score.
